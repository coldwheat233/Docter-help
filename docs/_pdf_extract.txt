一、项目基本信息  
二、立项背景及必要性  
（产品经理：董骐睿）
当前存在的问题 ：传统医疗预约流程依赖人工电话 / 前台登记，存在三方面痛点：
1. 高峰时段话务拥堵，患者等待时间长，预约体验差；
2. 人工登记信息易错漏，医生排班与预约记录靠人工同步，效率低；
3. 预约确认依赖人工回访，爽约率高，诊室资源利用率不足。
外部机会 ：大语言模型（ LLM ）与智能体（ Agent ）技术日趋成熟， LangGraph 等编排框架已具备生产
级能力，可在低成本下构建 " 能听懂人话、能操作业务系统 " 的多智能体系统，替代重复性人工劳动。
必要性 ：
业务侧：预约咨询是标准化程度高、规则清晰的流程型业务，非常适合智能体自动化；
技术侧：单一大模型直接应答存在意图漂移、不可控操作等风险，需采用多智能体分工  + 人工把关
（Human-in-the-Loop ）的架构来保证可靠性；
团队侧：本实习项目可让团队完整实践  Agent 系统开发的 " 需求分析  →  架构设计  →  实现  →  测试验
收" 全流程，沉淀可复用的多智能体开发能力。
三、项目目标  
1. 总体目标  
构建一套基于  LangGraph 的多智能体医疗预约系统：用户通过自然语言描述病情与就诊需求，系统自动
完成 问诊信息收集  →  时间推荐  →  预约确认 全流程，关键操作（正式落库预约）由人工确认后执行，最
终形成可演示、可讲解、可扩展的完整智能体应用。
