## 二、5 张表

### 2.1 `departments`（科室表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK, AUTO | 内部 ID |
| code | TEXT | UNIQUE, NOT NULL | 内部编码（如 'IM'） |
| name | TEXT | UNIQUE, NOT NULL | 中文名（如 '心内科'） |
| description | TEXT | | 简介 |
| created_at | TIMESTAMP | DEFAULT NOW | |

**索引**：`idx_departments_name (name)`

### 2.2 `doctors`（医生表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK, AUTO | |
| name | TEXT | NOT NULL | 医生姓名 |
| department | TEXT | FK→departments.name, NOT NULL | 所属科室 |
| title | TEXT | DEFAULT '主治医师' | 主任/副主任/主治/住院 |
| specialty | TEXT | | 专长 |
| intro | TEXT | | 简介 |
| is_active | BOOLEAN | DEFAULT 1 | 是否在岗 |
| created_at | TIMESTAMP | DEFAULT NOW | |

**索引**：
- `idx_doctors_department (department)`
- `idx_doctors_active (is_active)`

### 2.3 `schedules`（排班表，核心）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK, AUTO | |
| doctor_id | INTEGER | FK→doctors.id, NOT NULL | |
| schedule_date | DATE | NOT NULL | YYYY-MM-DD |
| time_slot | TEXT | NOT NULL, CHECK IN ('morning','afternoon','evening') | 时段 |
| start_time | TIME | NOT NULL | HH:MM |
| end_time | TIME | NOT NULL | HH:MM |
| capacity | INTEGER | DEFAULT 20 | 该时段总号源 |
| remaining | INTEGER | DEFAULT 20 | 剩余号源 |
| is_available | BOOLEAN | DEFAULT 1 | 是否可预约 |
| created_at | TIMESTAMP | DEFAULT NOW | |

**唯一约束**：`UNIQUE (doctor_id, schedule_date, time_slot)` —— 同一医生同时段不重复

**索引**：
- `idx_schedules_date (schedule_date)`
- `idx_schedules_doctor_date (doctor_id, schedule_date)`
- `idx_schedules_available (is_available, schedule_date, remaining)` —— 联合索引，支持"查某日可用排班"的高频查询

**时段定义**：
- morning: 08:00-12:00
- afternoon: 14:00-18:00
- evening: 18:30-21:00

### 2.4 `patients`（患者表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | TEXT | PK | 患者 ID（如 'P20240001'） |
| name | TEXT | NOT NULL | 姓名 |
| phone | TEXT | | 手机号 |
| insurance_no | TEXT | | 医保号 |
| birth_date | DATE | | |
| gender | TEXT | CHECK IN ('M','F','O') | |
| created_at | TIMESTAMP | DEFAULT NOW | |

**索引**：`idx_patients_phone (phone)`

### 2.5 `appointments`（预约表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | TEXT | PK | 预约单号（'A' + YYYYMMDD + 4 位随机） |
| patient_id | TEXT | FK→patients.id, NOT NULL | |
| doctor_id | INTEGER | FK→doctors.id, NOT NULL | |
| schedule_id | INTEGER | FK→schedules.id, NOT NULL | |
| symptoms | TEXT | | 主诉 |
| duration | TEXT | | 病程 |
| severity | TEXT | | 严重程度 |
| status | TEXT | DEFAULT 'pending', CHECK IN (...) | 状态 |
| confirmed_at | TIMESTAMP | | 确认时间 |
| cancelled_at | TIMESTAMP | | 取消时间 |
| notes | TEXT | | 备注 |
| created_at | TIMESTAMP | DEFAULT NOW | |
| updated_at | TIMESTAMP | DEFAULT NOW | |

**status 取值**：`pending` / `confirmed` / `cancelled` / `completed` / `no_show`

**索引**：
- `idx_appointments_patient (patient_id)`
- `idx_appointments_doctor (doctor_id)`
- `idx_appointments_status (status)`
- `idx_appointments_schedule (schedule_id)`

## 三、数据流

### 3.1 创建预约（落库）

```
1. 调 set_appointment(patient_id, doctor_id, schedule_id)
    ↓
2. AppointmentRepository.create() 内部：
    a. ScheduleRepository.decrement_remaining(schedule_id)  -- 原子扣号源
    b. INSERT INTO appointments VALUES (..., 'confirmed', NOW())
    c. 事务提交
    ↓
3. 返回 appointment_id (如 'A20260901ABCD')
```

⚠️ 第 1 周 stub：Agent 不会真正调用此工具
✅ 第 2 周实现：confirmer_agent 调此工具前必须 HITL 审批

### 3.2 取消预约

```
1. 调 cancel_appointment(appointment_id)
    ↓
2. AppointmentRepository.update_status(id, 'cancelled')
    a. UPDATE appointments SET status='cancelled', cancelled_at=NOW()
    ↓
3. 注：当前实现不退回 schedule.remaining（待第 2 周决定是否要加）
```

### 3.3 改约

```
1. 调 reschedule_appointment(id, new_schedule_id)
    ↓
2. AppointmentRepository.update_schedule(id, new_schedule_id) 内部：
    a. 读旧 schedule_id
    b. UPDATE schedules SET remaining = remaining + 1 WHERE id = old_id  -- 退回
    c. ScheduleRepository.decrement_remaining(new_schedule_id)  -- 扣新
    d. UPDATE appointments SET schedule_id = new_schedule_id
    ↓
3. 事务提交
```

## 五、查询模式

| 业务 | SQL 模式 | 索引 |
|---|---|---|
| 查某科室某日可用排班 | `WHERE department=? AND schedule_date=? AND is_available=1 AND remaining>=1` | idx_schedules_available |
| 查某医生所有排班 | `WHERE doctor_id=? ORDER BY schedule_date` | idx_schedules_doctor_date |
| 查某患者未完成预约 | `WHERE patient_id=? AND status IN ('pending','confirmed')` | idx_appointments_patient |
| 统计每日预约量 | `SELECT schedule_date, COUNT(*) FROM appointments GROUP BY schedule_date` | idx_appointments_schedule |

## 六、扩展点

1. **HIS 系统对接**：把 `ScheduleRepository.find_available` 改为调医院 API
2. **支付集成**：appointments 加 `payment_id` 字段
3. **医生排班规则**：加 `schedule_rules` 表，存轮班模板
4. **审计日志**：加 `audit_log` 表，记录所有 HITL 决策
5. **多端同步**：迁移到 PostgreSQL，用 `pgvector` 做症状相似度检索

## 七、迁移到生产

- SQLite → PostgreSQL（更大并发）
- 加 `pg_trgm` 索引做症状模糊匹配
- 用 `psycopg` 替代 `sqlite3`（连接池）
- 启动时跑 `alembic upgrade head` 做 schema 迁移
