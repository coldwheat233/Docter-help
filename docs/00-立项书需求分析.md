## 一、项目基本信息 [P0]

- 7 人团队 / 3 周 / Python + LangGraph
- 责任划分：产品（董骐睿）、技术（顾竣熙）、项目（白雷）、开发（张艺博/陈熙睿/董超）、测试与文档（陈家兴）
- 立项日期：2026-08-24
- 计划完成：2026-09 中旬

## 二、立项背景及必要性 [P0]

- 痛点：传统医疗预约流程（电话/前台）效率低、错漏多、爽约率高
- 外部机会：LLM + Agent + LangGraph 已具备生产能力
- 必要性：业务标准化适合自动化、单一 LLM 不可控需要 HITL、团队需要 Agent 开发能力沉淀

## 三、项目目标

### 1. 总体目标 [P0]

构建 LangGraph 多智能体医疗预约系统，用户自然语言描述病情，系统自动完成 **问诊信息收集 → 时间推荐 → 预约确认** 全流程，关键操作（正式落库预约）由人工确认后执行。

### 2. 可量化指标 [P1, P2]

| 指标 | 目标 | 验收方式 |
|---|---|---|
| 意图路由准确率 | ≥ 90% | 20+ 测试用例，实测统计 |
| 预约流程完整率 | ≥ 85% | 端到端 demo 跑通统计 |
| 关键操作人工确认率 | 100% | 代码审查 HITL interrupt |
| 单次预约对话平均时间 | ≤ 3 分钟 | demo 实测 |
| 系统可用性 | 全程无崩溃 | 演示环境 30 分钟稳定性测试 |

### 核心技术方案 [P0]

- Python 3.11（不用 3.13，langgraph-supervisor 兼容性未明确）
- langgraph 0.3+ / langgraph-supervisor 0.0.15 / langgraph-swarm 0.0.14
- langchain-deepseek（用 deepseek-chat，不用 deepseek-reasoner）
- SQLite 5 张表
- LangSmith 4 个环境变量配置
- 参考 pareshraut/Langgraph-agents 的 `doc-agent/` 子项目
