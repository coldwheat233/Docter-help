## 一、State 接口

### 1.1 `AppointmentState`（顶层 State）

定义位置：`src/medical_agent/state.py`

```python
class AppointmentState(TypedDict, total=False):
    # 消息历史（自动累加）
    messages: Annotated[list, add_messages]

    # 用户身份
    patient_id: str | None           # [input]  第 2 周接入用户系统

    # 原始查询
    raw_query: str | None            # [input]  用户最新一条自然语言

    # 路由结果
    intent: Literal["consult", "book", "reschedule", "cancel", "unknown"]  # [output]

    # 问诊信息
    symptoms: str | None             # [output] 主诉
    duration: str | None             # [output] 病程（如 "3 天"）
    severity: Literal["mild", "moderate", "severe"] | None  # [output]
    department: str | None           # [output] 科室

    # 排班
    preferred_date: str | None       # [input]  YYYY-MM-DD
    preferred_time_slot: Literal["morning", "afternoon", "evening"] | None
    recommended_slots: list[dict]    # [output] 推荐时段
    selected_slot: dict | None       # [input]  用户选定的时段

    # 流程控制
    current_step: Literal["init", "intake", "schedule", "confirm", "done"]
    pending_human_confirm: bool      # [internal] HITL 暂停标志

    # 落库结果
    appointment_id: str | None       # [output] A + YYYYMMDD + 4 位
    status: Literal["pending", "confirmed", "cancelled", "completed", "no_show"]
    final_answer: str | None         # [output] 给用户的最终回复
```

**字段约束**

- 所有 None 值表示"未收集"
- 字符串字段最大长度：255
- `recommended_slots` 每项 schema：
  ```python
  {
    "schedule_id": int,
    "doctor_id": int,
    "doctor_name": str,
    "doctor_title": str,
    "department": str,
    "schedule_date": "YYYY-MM-DD",
    "time_slot": "morning|afternoon|evening",
    "start_time": "HH:MM",
    "end_time": "HH:MM",
    "remaining": int
  }
  ```

### 3.2 Agent 名称常量

```python
ROUTER_AGENT_NAME = "router_agent"
INTAKE_AGENT_NAME = "intake_agent"
SCHEDULER_AGENT_NAME = "scheduler_agent"
CONFIRMER_AGENT_NAME = "confirmer_agent"
```

### 3.3 约束

- 每个 Agent 必须有唯一 `name`（Supervisor 通过它路由）
- 每个 Agent 必须能接受 `AppointmentState` 类型的输入
- 每个 Agent 输出的 messages 自动合并到 State
- 不允许 Agent 之间直接通信（必须经 Supervisor 路由）
